# NAA — projekty stron

Statyczne strony HTML. Obrazy i fonty są osadzone w plikach, więc nie wymagają npm, kompilacji ani dodatkowych zasobów.

## Pliki

- `index.html` — lista wszystkich stron
- `NAA-Homepage-Bold2.html` — strona główna, wersja Bold2
- `NAA-Category-Bold2.html` — strona kategorii (Wood Coatings), Bold2
- `NAA-Product-Bold2.html` — strona produktu, Bold2
- `NAA-Homepage-Bold.html` — wcześniejsza wersja strony głównej (Bold)
- `NAA-Homepage-Redesign.html` — wcześniejsza wersja strony głównej (Redesign)

## Uwagi do Bold2

Filtry, sortowanie, paginacja, warianty, galeria i koszyk demo działają lokalnie. Nazwy produktów, opisy, ceny i opcje to placeholdery z projektu Figma i wymagają finalnych danych przed wdrożeniem.

Układ na szerokich ekranach: przy 1920 px treść ma 1440 px i 120 px białego marginesu z każdej strony, przy 2560 px — 1600 px treści i 240 px marginesu. Biała ramka ma maksymalnie 2080 px, dalej widać szare tło.

## Hosting

Na Netlify: build command pusty, publish directory — katalog główny.
